# Naming: plain words where they exist, metaphor only where they do not

Status: **proposed**, 2026-09-01. Lands before the agent-loop plan
(`2026-09-01-agent-loop.md`) so every new verb is born with its final
name. Authority: ONTOLOGY.md for the definitions (which do not change),
PORCELAIN.md for records (which do), the wire contract (which takes its
one declared break here).

## The problem

Grid's verbs are mostly plain English and guessable. Its nouns are a
nautical vocabulary that is consistent and precise once learned, and a
tax before that — `zoc`, `xte`, `leadline`, `made-good`, `wake`, `track`,
`leg`, `fix` each cost a reader one `grid explain` call or one wrong
guess, and an agent under context pressure guesses. Two of them are worse
than opaque: `track` reads as *monitor* to every developer and means
*promise file*; `fix` reads as *bug fix* in a coding tool and means
*position*. On the verb side, four verbs answer "is my change ok"
(`gate`, `review`, and the agent-loop plan's `check` and `inspect`), one
verb collides with another (`cache check`), and `bind` reads as name
binding.

## The rule

Plain word wherever one exists at the same precision. The metaphor stays
only where the plain word is wrong or missing — `drift`, `aground`,
`covenant`, `datum`, `callsign` earn their place. Every renamed word stays
**answerable** in `grid explain` (an alias table maps the old token to the
new definition, and the definition names its origin) and is **never
emitted** again by any verb.

## Keep

`datum`, `sig`, `shape`, `callsign`, `handle`, `snapshot`, `segment`,
`chart`, `membership`, `survey`, `drift`, `covenant`, `aground`,
`closure`, `hop`, `path`, `fork`, `anchor`, `delta` (a watch delta), the
evidence grades `proven` / `observed` / `modeled` / `heuristic`, and the
verbs `survey diff drift watch resolve uses scope orphans hotspots roots
log suspects gate todo edit explain serve version`.

## Rename

### Nouns (ONTOLOGY tokens; definitions unchanged, origin noted)

| now | new | why |
|---|---|---|
| `zoc` | `grade` | ONTOLOGY already defines it as "evidence grade"; CATZOC is the origin, noted in the definition |
| `xte` | `verdict` | the gate's output is a verdict; `pass` / `hold` are already plain |
| `leadline` | `walk` | `grid.query.walk` already calls it that |
| `made-good` | `diff` | it is the diff between two snapshots; `grid diff` is the verb |
| `wake` | `trace` | ONTOLOGY defines it as "a runtime trace"; `stale-trace` already uses the plain word |
| `track` | `plan` | reads as *monitor*; it is the promise file |
| `leg` | `edit` | one edit of one definition; `grid log` lists them |
| `fix` | `position` | reads as *bug fix*; it is a position in code |
| `log` (the noun: the whole patch DAG) | `history` | the verb `grid log` keeps its git-familiar name |

### Verbs

| now | new | why |
|---|---|---|
| `bind A B --via w`, `bind --list` | `covenant A B --via w`, `covenant --list` | `bind` is name binding to a programmer |
| `track lint`, `track estimate` | `plan lint`, `plan estimate` | follows the noun |
| `gate <track> [head]` | `gate <plan> [head]` | argument only; the verb stays the CI form |
| `review <track> [head]` | `check --plan <plan> --why [head]` | folded: one verb answers "is my change ok"; `--why` embeds the paths `review` printed |
| `cache check`, `cache record` | `cache lookup`, `cache record` | `check` is taken |
| `wake ingest`, `wake diff` | `trace ingest`, `trace diff` | follows the noun |
| `bisect` | removed from the usage text; the verb still answers | a verb that always refuses (C23) is worse than absent until retained history exists |

The agent-loop plan's verbs, renamed before they exist: `inspect` →
`check` (the composite; the compile wrapper becomes its component),
`pack` → `scope --bodies N --sigs M --budget T --since S`, `interfere`
and `test` unchanged. The agent-facing surface is therefore `check`,
`test`, `scope`, with `gate` as the plan-required CI alias.

### Porcelain records

`leg` → `edit`; `bind` → `covenant`. Every other tag stays. The evidence
column already prints the four grade words and never the word `zoc`.
Version 1.6.0 → **2.0.0**: renaming a tag is a major by PORCELAIN.md's own
rule, and it is one major, taken once.

### Wire: declared epoch 0 → 1

The additive-only rule forbids a rename inside an epoch. The honest path
is the one the segment format already follows: a **declared** break, one
time, before any consumer exists. `docs/wire-v0.openrpc.json` becomes
`docs/wire-v1.openrpc.json` with `info.version` `1.0.0`; `gen-wire.py`
regenerates `crates/wire`; nothing serves v0 afterwards, because nothing
consumes it.

| v0 | v1 |
|---|---|
| field `zoc` (every edge, filter, rule) | `grade` |
| `Wake`, `WakeObservation`, `WakeEndpoint`, `WakeDiff*`, `WakeId`, `wake_id`, `grid.wake.ingest`, `grid.wake.diff` | `Trace`, `TraceObservation`, `TraceEndpoint`, `TraceDiff*`, `TraceId`, `trace_id`, `grid.trace.ingest`, `grid.trace.diff` |
| `Track`, `TrackDelta`, `TrackDefPromise*`, `TrackEdgePromise`, `TrackId`, `grid.track.lint`, `grid.track.estimate` | `Plan`, `PlanDelta`, `PlanDefPromise*`, `PlanEdgePromise`, `PlanId`, `grid.plan.lint`, `grid.plan.estimate` |
| `XteVerdict` | `GateVerdict` |
| `MadeGood` | `Diff` |
| `LeadlineResult`, `LeadlineResultStats` | `WalkResult`, `WalkStats` |
| `grid.review.pack`, `ReviewPack*` | `grid.check` with `why: Option<…>` carrying what the pack carried |
| any type or field spelled after `fix` (the ontology noun) | `position` |
| any type or field spelled after `leg` | `edit` |

`grid.gate.check`, `grid.query.walk`, `grid.anchor.carry`, `grid.delta`,
`grid.scope`, `grid.suspects`, `grid.bisect`, `grid.drift`, `grid.cache.*`
keep their names. `grid version` reports the wire epoch beside the
porcelain version.

### Disk

`.grid/wakes` → `.grid/traces`. On open, when the old directory exists
and the new one does not, it is renamed once; retained traces are user
data and are never dropped by a rename. `.grid/cache`, `.grid/chart`,
`.grid/covenants.json`, `.grid/invariants.json` unchanged.

### Crates

`grid-wake` → `grid-trace` (`crates/trace`), `grid-xte` → `grid-gate`
(`crates/gate`), `grid-leadline` → `grid-walk` (`crates/walk`).
Proprietary and unpublished, so this is churn only; ASSURANCE.md's
dependency-justification lines and the `check-*.sh` scripts follow.

### Documents

ONTOLOGY.md: each renamed token's row uses the new word and its
definition ends with the origin — e.g. `grade` … "(after *zoc*, CATZOC:
real charts grade every sounding's confidence)". The alias table
`grid explain` reads is generated from a new `## Former names` table in
the same file (`| old | new |`), parsed by `crates/grid/build.rs` beside
the existing ones, so `grid explain zoc` answers with `grade`'s
definition and says what it used to be called. LANG_RS.md, ASSURANCE.md
(claim statements keep their numbers), PORCELAIN.md, README.md, and both
2026-09-01 plans follow mechanically.

## Sequencing (one PR per tier, gates green between)

```
1. CLI verbs + porcelain records + ONTOLOGY/PORCELAIN/README   (porcelain 2.0.0)
2. wire epoch 1: contract file, gen-wire, generated crate, conformance   (declared break)
3. crates and the disk directory, ASSURANCE lines, scripts               (churn)
```

Tier 1 and 2 are one break each and land together in one PR if the
tests allow it; tier 3 may follow separately.

## Tests

- **Conservatism, seen red first:** a conformance test runs every verb's
  usage and one representative invocation over the fixture repo and
  asserts that stdout and stderr contain none of the retired tokens as
  words — `zoc`, `xte`, `leadline`, `made-good`, `wake`, `track`, `leg`,
  `bind` as a tag — except inside an `explain` answer that names a former
  name. Red today on `bind` and `leg` records and on `grid wake …` hints.
- **Explain aliases:** `grid explain zoc`, `xte`, `leadline`, `made-good`,
  `wake`, `track`, `leg`, `fix` each answer with the new token's
  definition and the sentence "formerly `<old>`"; `grid explain grade`
  answers directly.
- **Wire:** the conformance suite passes against the v1 contract; a v0
  request naming a retired method (`grid.wake.ingest`) is refused with
  the standard unknown-method error, never silently mapped.
- **Disk:** a store with `.grid/wakes` opens, renames once, and the
  retained traces are byte-identical afterwards; a store with both
  directories refuses to guess (bad input, names both).
- **Property:** every fixture that exists today produces the same records
  modulo the renamed tags — the differential is a token-level rewrite of
  the expected files, so a behavior change cannot hide behind the rename.

## Rules for the executor

- No behavior change rides on this plan. A test that changes for any
  reason other than a renamed token is a bug in the rename.
- No new dependencies. Renames are `sed`-shaped edits plus the alias
  table; the build script's parser gains one table.
- Old words are never emitted. `grep` for each retired token across
  `crates/` and `docs/` after each tier; the only permitted survivors are
  the "Former names" table, origin notes in definitions, git history, and
  the two plan documents' own rename tables.
- The usual gates before every commit: `cargo fmt --all --check`, `cargo
  clippy --workspace --all-targets` (pedantic, deny), `cargo test
  --workspace`, `cargo deny check`, `scripts/check-assurance-links.sh`,
  `scripts/check-unsafe-confined.sh`.

## Cut line

- `callsign` → `name`: loses "the mutable name bound to an identity",
  which is the point of the word. Kept.
- `chart` → `graph`: no collision, no confusion. Kept.
- `datum` → `id`: `datum` carries "the reference everything is measured
  from", and `id` is every other tool's word for a counter. Kept.
- `aground` → `partial`: "partial" hides the certificate; `aground`
  means "stopped, with a stated radius that is complete". Kept.
